# 事务控制（Transaction）

> 事务是一组要么全部成功、要么全部失败的操作。ACID：原子性、一致性、隔离性、持久性。

---

## 1. 基本事务：COMMIT 与 ROLLBACK

```sql
-- 显式开启事务
START TRANSACTION;
-- 或
BEGIN;

-- 执行一系列操作
UPDATE students SET phone = '13800000001' WHERE id = 1;
UPDATE students SET phone = '13800000002' WHERE id = 2;
INSERT INTO enrollments (student_id, course_id, enrolled_at) VALUES (1, 2, CURDATE());

-- 一切正确，提交
COMMIT;

-- 如果中间发现问题，回滚
ROLLBACK;
```

## 2. 事务中的 SAVEPOINT（保存点）

```sql
START TRANSACTION;

INSERT INTO students (name, birthdate) VALUES ('测试生A', '2003-01-01');
SAVEPOINT sp1;                          -- 设置保存点

INSERT INTO students (name, birthdate) VALUES ('测试生B', '2003-02-02');
SAVEPOINT sp2;

INSERT INTO students (name, birthdate) VALUES ('测试生C', '2003-03-03');

-- 发现 B 和 C 插错了，只回滚到 sp1
ROLLBACK TO SAVEPOINT sp1;              -- A 保留，B、C 撤销

-- 释放保存点
RELEASE SAVEPOINT sp1;

COMMIT;                                  -- 最终只提交了 A
```

## 3. 自动提交控制

```sql
-- 查看当前自动提交状态
SELECT @@autocommit;          -- 1 = 自动提交，0 = 手动提交

-- 关闭自动提交（该会话内所有语句需手动 COMMIT）
SET autocommit = 0;

UPDATE students SET phone = '13900000000' WHERE id = 3;
-- 此时其他会话看不到此修改

COMMIT;                       -- 提交后其他会话才可见
-- 或 ROLLBACK 撤销

-- 恢复自动提交
SET autocommit = 1;
```

## 4. 并发场景：丢失更新

```sql
-- 会话A                                -- 会话B
START TRANSACTION;                     START TRANSACTION;
SELECT score FROM enrollments          SELECT score FROM enrollments
WHERE id = 1;  -- 得到 85              WHERE id = 1;  -- 也得到 85
UPDATE enrollments                     -- B 先提交，score 变成 90
SET score = 88 WHERE id = 1;           UPDATE enrollments
                                        SET score = 90 WHERE id = 1;
                                        COMMIT;
COMMIT;  -- score = 88 覆盖了 90
                                        -- B 的更新丢失了

-- 解决：用 SELECT ... FOR UPDATE 加锁
START TRANSACTION;
SELECT score FROM enrollments WHERE id = 1 FOR UPDATE;
-- 此时 B 的 SELECT ... FOR UPDATE 会阻塞，直到 A 提交
UPDATE enrollments SET score = 88 WHERE id = 1;
COMMIT;
```

## 5. 隔离级别演示：脏读

```sql
-- 会话A（读未提交）                     -- 会话B
SET SESSION TRANSACTION
ISOLATION LEVEL READ UNCOMMITTED;
START TRANSACTION;                     START TRANSACTION;
                                        UPDATE students
                                        SET phone = '11111111111'
                                        WHERE id = 1;
SELECT phone FROM students             -- 未提交也能读到
WHERE id = 1;  -- 读到 '11111111111'   ROLLBACK;  -- B 回滚了！
-- A 读到了 B 从未提交的脏数据
```

## 6. 隔离级别演示：不可重复读 vs 幻读

```sql
-- 不可重复读（READ COMMITTED 级别）
-- 会话A                                 -- 会话B
SET SESSION TRANSACTION
ISOLATION LEVEL READ COMMITTED;
START TRANSACTION;                     START TRANSACTION;
SELECT score FROM enrollments          UPDATE enrollments
WHERE id = 1;  -- 85                  SET score = 90 WHERE id = 1;
                                        COMMIT;
SELECT score FROM enrollments
WHERE id = 1;  -- 90（同一事务内两次读到不同值！这是不可重复读）

-- 幻读（REPEATABLE READ 级别，MVCC 可部分避免）
-- 会话A                                 -- 会话B
START TRANSACTION;                     START TRANSACTION;
SELECT COUNT(*) FROM students          INSERT INTO students (name)
WHERE gender = 'F';  -- 5             VALUES ('新女生');
                                        COMMIT;
SELECT COUNT(*) FROM students
WHERE gender = 'F';  -- 5（MySQL MVCC 避免了幻读）
```

## 7. SELECT ... FOR UPDATE（排他锁）

```sql
START TRANSACTION;

-- 锁定即将修改的行，阻止其他事务修改
SELECT * FROM students WHERE id IN (1, 2, 3) FOR UPDATE;

UPDATE students SET phone = '13000000000' WHERE id = 1;
UPDATE students SET phone = '13000000001' WHERE id = 2;

COMMIT;
```

## 8. SELECT ... LOCK IN SHARE MODE（共享锁，MySQL 8.0 改为 FOR SHARE）

```sql
START TRANSACTION;

-- 加共享锁：允许别人读，不允许别人改
SELECT * FROM courses WHERE id = 1 FOR SHARE;
-- MySQL 8.0 之前：SELECT * FROM courses WHERE id = 1 LOCK IN SHARE MODE;

-- 可以安全读取，但暂不修改
COMMIT;
```

## 9. 死锁示例

```sql
-- 会话A                                -- 会话B
START TRANSACTION;                     START TRANSACTION;
UPDATE students
SET phone = 'a' WHERE id = 1;          UPDATE students
-- A 锁住了 id=1                       SET phone = 'b' WHERE id = 2;
                                        -- B 锁住了 id=2
UPDATE students
SET phone = 'a' WHERE id = 2;          UPDATE students
-- A 等待 B 释放 id=2                  SET phone = 'b' WHERE id = 1;
                                        -- B 等待 A 释放 id=1
                                        -- 死锁！MySQL 自动检测并回滚一方
```

**避免死锁的策略：**
- 始终按相同顺序访问资源（如都按 id 升序）
- 缩短事务时间
- 必要时用 `SELECT ... FOR UPDATE` 提前锁定

## 10. 事务嵌套注意

```sql
-- MySQL 中 START TRANSACTION 会自动提交前一个事务
START TRANSACTION;
UPDATE students SET phone = '1' WHERE id = 1;
START TRANSACTION;   -- 前一个事务自动提交！
UPDATE students SET phone = '2' WHERE id = 2;
ROLLBACK;            -- 只回滚第二个事务，id=1 的修改已提交
```

## 隔离级别对比

| 级别 | 脏读 | 不可重复读 | 幻读 |
|------|------|-----------|------|
| READ UNCOMMITTED | 可能 | 可能 | 可能 |
| READ COMMITTED | 避免 | 可能 | 可能 |
| REPEATABLE READ (MySQL 默认) | 避免 | 避免 | 部分避免 |
| SERIALIZABLE | 避免 | 避免 | 避免 |
