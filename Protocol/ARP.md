# ARP

**ARP（Address Resolution Protocol）是局域网的身份识别员**。负责将 IP 地址解析为 MAC 地址，实现在同一本地网络中的设备直连通信。

## 一句话速查

| 项目 | 说明 |
|------|------|
| **工作层级** | 数据链路层（第 2 层） |
| **解析** | IP 地址 → MAC 地址 |
| **作用范围** | 单个局域网（LAN）内 |
| **核心缺陷** | 无认证机制，无条件信任 ARP 响应 |
| **主要攻击** | ARP 欺骗 → 中间人 / DoS |
| **防御** | DAI + DHCP Snooping / 静态 ARP / 加密通信 |

---

## 为什么需要 ARP？

网络中通信最终通过 MAC 地址传输数据帧，而用户使用的是 IP 地址。ARP 解决的就是这个"翻译"问题：**已知目标 IP，如何获取其 MAC 地址？**

---

## 工作原理

假设局域网内有两台设备：

- **设备 A**：IP = `192.168.1.10`，MAC = `AA:AA:AA:AA:AA:AA`
- **设备 B**：IP = `192.168.1.20`，MAC = `BB:BB:BB:BB:BB:BB`

当 A 想与 B 通信时：

```
① A 检查本地 ARP 缓存表 → 未找到 B 的 MAC
        ↓
② A 发送 ARP 请求（广播，MAC: FF:FF:FF:FF:FF:FF）
   "谁的 IP 是 192.168.1.20？请告诉 192.168.1.10"
        ↓
③ 所有设备收到广播 → 仅 B 响应（单播）
   "我是 192.168.1.20，我的 MAC 是 BB:BB:BB:BB:BB:BB"
        ↓
④ A 收到响应 → 存入 ARP 缓存表（有 TTL 过期时间）
        ↓
⑤ A 封装以太网帧 → 正常通信
```

---

## 核心安全缺陷

ARP 设计上**无任何身份验证机制**：

- 设备会**无条件信任收到的 ARP 响应**，即使没有发送过对应请求
- 设备会**无条件信任收到的 ARP 请求**，并更新自身缓存

---

## ARP 欺骗 / 毒化攻击

### 1. 中间人攻击（MitM）

攻击者 C 向 A 和 B 分别发送伪造的 ARP 响应，将双方的 IP 映射到 C 的 MAC 地址。

```
正常通信：  A ←——————→ B
攻击后：    A ←——→ C ←——→ B  （C 可窃听、记录、篡改所有流量）
```

**后果**：
- 窃听敏感信息（账号、密码、聊天内容）
- 会话劫持（夺取已登录的 Web 会话）
- 数据篡改（注入恶意代码、修改转账信息）

### 2. 拒绝服务攻击（DoS）

攻击者向网关发送伪造的 ARP 响应，将目标 A 的 IP 映射到一个不存在的 MAC 地址。网关发往 A 的所有数据包丢失 → A 网络中断。

---

## 防护与缓解

| 措施 | 原理 | 适用场景 |
|------|------|----------|
| **DAI（动态 ARP 检测）** | 交换机验证 ARP 报文中 IP-MAC 映射的合法性 | 企业网络（需交换机支持） |
| **DHCP Snooping** | 建立可信 IP-MAC 绑定数据库，供 DAI 使用 | 配合 DAI 使用 |
| **静态 ARP 条目** | 手动设置关键设备的固定 IP-MAC 映射 | 服务器/网关等少量关键设备 |
| **加密通信（HTTPS / VPN）** | 即使被 ARP 欺骗，窃听到的是密文 | 所有用户 |
| **ARP 防火墙** | 监控本机 ARP 缓存表异常变更并告警 | 个人 PC |
| **VLAN 网络分段** | 限制 ARP 广播范围（同一 VLAN 内） | 大型网络 |

> **最有效组合**：企业交换机上部署 DAI + DHCP Snooping，终端用户启用 VPN/HTTPS 加密通信。

## 常用命令

```bash
# 查看 ARP 缓存表（Windows / Linux）
arp -a

# 清除 ARP 缓存（Linux）
ip neigh flush all
arp -d <IP>               # 删除单条

# 清除 ARP 缓存（Windows）
arp -d *
netsh interface ip delete arpcache

# 添加静态 ARP 条目（Linux）
arp -s 192.168.1.1 00:1a:2b:3c:4d:5e

# 添加静态 ARP 条目（Windows）
arp -s 192.168.1.1 00-1a-2b-3c-4d-5e

# 查看 ARP 表变化（实时监听）
ip monitor neigh          # Linux
```
