FOFA（**F**orget **O**ther **F**uzzy **A**ppliances）是一款非常强大的网络空间测绘搜索引擎，它通过扫描全球互联网资产，允许用户使用特定的语法来快速、精准地定位目标资产。

以下是FOFA搜索语法的详细说明，分为**基础语法**、**高级语法**和**技巧与示例**三部分。

### 一、 基础搜索语法（核心）

FOFA的核心语法是 `key=value` 的形式，多个条件可以用逻辑运算符连接。

#### 1. 常用搜索字段

|   |   |   |   |
|---|---|---|---|
|字段名|说明|示例|用途|
|**`domain`**|搜索指定域名|`domain="fofa.info"`|查找主域名及其子域名的资产|
|**`host`**|搜索与特定域名匹配的资产|`host=".gov.cn"`|搜索包含该字段的所有域名资产|
|**`ip`**|搜索指定IP或CIDR段的资产|`ip="192.168.1.1/24"`|查找某个IP或整个网段的资产|
|**`port`**|搜索指定端口的服务|`port="8080"`|查找开放了特定端口的服务|
|**`country`**|按国家代码搜索|`country="CN"`|查找位于中国的资产|
|**`region`**|按地区（省/州）搜索|`region="Zhejiang"`|查找位于浙江的资产|
|**`city`**|按城市搜索|`city="Hangzhou"`|查找位于杭州的资产|
|**`title`**|按网页标题搜索|`title="后台登录"`|查找标题中包含关键词的网站|
|**`body`**|按网页正文内容搜索|`body="Powered by WordPress"`|查找正文中包含特定内容的网站|
|**`header`**|按HTTP响应头搜索|`header="nginx"`|查找Web服务器为nginx的资产|
|**`server`**|等同于 `header="server"`|`server="Microsoft-IIS/10"`|查找特定版本的服务端软件|
|**`protocol`**|按应用层协议搜索|`protocol="ftp"`|查找FTP服务|
|**`banner`**|按端口服务banner信息搜索|`banner="mysql"`|查找MySQL数据库服务|
|**`cert`**|按SSL证书信息搜索|`cert="google.com"`|查找使用包含该域名证书的资产|
|**`icon_hash`**|按网站图标的Hash值搜索|`icon_hash="-247388890"`|**精准定位**同一套系统，无视URL变化|
|**`status_code`**|按HTTP状态码搜索|`status_code="403"`|查找返回403禁止访问的页面|
|**`is_domain`**|判断是否为域名资产|`is_domain=true`|筛选出是域名的资产|
|**`is_ipv6`**|判断是否为IPv6资产|`is_ipv6=true`|筛选出IPv6地址的资产|
|**`os`**|按操作系统搜索|`os="windows"`|查找运行Windows系统的设备|

#### 2. 逻辑运算符

|   |   |   |   |   |   |   |
|---|---|---|---|---|---|---|
|运算符|说明|示例|||||
|**`&&`** (与)|同时满足多个条件|`title="login" && body="admin"`|||||
|**`||`** (或)|满足其中一个条件即可|`server="nginx"||server="apache"`|
|**`!=`** (非)|排除某个条件|`city!="Beijing"`|||||
|**`=`** (等于)|精确匹配（需用双引号）|`domain="example.com"`|||||
|**`==`** (全等)|精确匹配（需用双引号）|`domain=="example.com"`|||||
|**`~=`** (正则匹配)|使用正则表达式匹配|`domain~=".*\.example\.com"`|||||

### 二、 高级搜索语法

#### 1. 搜索语法函数

这些函数可以让你进行更复杂的查询。

|   |   |   |
|---|---|---|
|函数|说明|示例|
|**`cidr`**|更专业的CIDR地址块查询|`cidr="192.168.1.1/24"`|
|**`ip_range`**|搜索一个IP范围内的资产|`ip_range="192.168.1.1, 192.168.2.255"`|

#### 2. 时间限定搜索

可以搜索在特定时间范围内上线或更新的资产。

|   |   |   |
|---|---|---|
|语法|说明|示例|
|**`after`**|搜索在指定时间之后更新的资产|`after="2023-01-01"`|
|**`before`**|搜索在指定时间之前更新的资产|`before="2023-12-31"`|

示例：`domain="fofa.info" && after="2023-01-01" && before="2023-12-31"`

### 三、 搜索技巧与实用示例

#### 1. 精准资产发现

- **查找某公司的所有Web服务**：

`domain="abc.com" && port="443"`

- **查找使用特定CMS（如WordPress）的网站**：

`body="wp-content" && title="Welcome to WordPress"`

`icon_hash="-1472471659"` (使用WordPress的图标Hash，更精准)

#### 2. 漏洞影响范围评估

- **查找暴露在公网的Jenkins管理后台**：

`title="Jenkins" && port="8080" && country="CN"`

- **查找某漏洞组件（如Log4j）**：

`header="x-powered-by" && header~="log4j"`

#### 3. 网络空间测绘

- **查找中国境内所有开放的Redis服务（无密码）**：

`port="6379" && country="CN" && banner="redis"`

- **查找所有使用了Let's Encrypt证书的域名**：

`cert="Let's Encrypt"`

#### 4. 图标Hash (`icon_hash`) 的高级用法

这是FOFA最强大的功能之一。你可以先获取一个目标网站的Favicon.ico图标，然后使用FOFA提供的工具（或在线计算）计算出其 **`mmh3`** Hash值，用这个值可以找到互联网上所有使用相同图标的系统，即使它们的IP、域名、标题完全不同。

- 示例：`icon_hash="-247388890"` (某OA系统的图标Hash)

#### 5. 排除干扰项

在搜索管理后台时，经常会有很多无关结果，可以使用 `!=` 来排除。

- `title="登录" && body="admin" && city!="Beijing"`

---

### 四、 注意事项

1. **精确匹配与模糊匹配**：使用 `=` 或 `==` 时，值要用**双引号** `""` 括起来。模糊搜索可以直接写值，但不推荐，容易有杂音。
2. **权限与数量**：非会员用户查看的搜索结果数量有限制，高级语法和完整数据需要会员权限。
3. **合法性**：请务必在合法授权的前提下使用FOFA进行安全测试和资产梳理，切勿用于未授权的扫描和渗透测试。
4. **官方文档**：FOFA会持续更新语法和字段，最权威的参考永远是**官方文档**：[https://fofa.info/static_pages/help](https://fofa.info/static_pages/help)
