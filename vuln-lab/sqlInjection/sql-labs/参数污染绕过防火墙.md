    function java_implimentation($query_string)
    {
        $q_s = $query_string;
        $qs_array= explode("&",$q_s);
    
    
        foreach($qs_array as $key => $value)
        {
            $val=substr($value,0,2);
            if($val=="id")
            {
                $id_value=substr($value,3,30); 
                return $id_value;
                echo "<br>";
                break;
            }
    
        }
    
    }
    函数功能解析
    作用：从查询字符串（query_string）中提取第一个名为id的参数值。
    关键逻辑：
    用&分割查询字符串（如"id=123&name=foo" → ["id=123", "name=foo"]）
    检查每项前2字符是否为"id"，若是则提取=后的值（最多30字符）然后退出遍历。
    
    
    也就是如果query_string为id=1&id=2这个函数只会读读取id=1中的1，然后退出，并不会对id=2处理。
