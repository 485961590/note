### \_\_getitem\_\_()
getitem()是python的一个魔法方法对字典使用时,传入字符串,返回字典相应键所对应的值当对列表使用时,传入整数返回列表对应索引的值。
它允许对象实现索引和切片操作，使对象表现得像序列或映射类型。
**列表风格**
```python
class MyCollection:
    def __init__(self, data):
        self.data = data
    
    def __getitem__(self, key):
        return self.data[key]

# 使用示例
obj = MyCollection([1, 2, 3, 4, 5])
print(obj[0])    # 输出: 1
print(obj[2])    # 输出: 3
```
**字典风格的 `__getitem__`**
 ```python
class Config:
    def __init__(self):
        self._settings = {
            'host': 'localhost',
            'port': 8080,
            'debug': True
        }
    
    def __getitem__(self, key):
        if key in self._settings:
            return self._settings[key]
        else:
            raise KeyError(f"配置项 '{key}' 不存在")
    
    def __setitem__(self, key, value):
        self._settings[key] = value
    
    def keys(self):
        return self._settings.keys()

# 使用示例
config = Config()
print(config['host'])    # 输出: localhost
print(config['port'])    # 输出: 8080

config['timeout'] = 30   # 添加新配置
```

```jinja2

join
{% set a=dict(__cla=a,ss__=a)|join %}{{""[a]}}
	- `dict(__cla=a, ss__=a)` 创建一个字典
	- 字典的键是 `"__cla"` 和 `"ss__"`
	- 字典的值都是变量 `a`（此时 `a` 还未定义，但在 Jinja2 中会如何处理？）
	- `|join` 将字典的所有键连接成一个字符串
{% set a=['__cla','ss__']|join %}{{""[a]}}
	- `['__cla','ss__']` 创建一个列表
	- `|join` 将列表的所有元素连接成一个字符串
	- 结果是 `"__cla" + "ss__" = "__class__"`
```

```jinja2
{{ ''[chr(95)%2bchr(95)%2bchr(99)%2bchr(108)%2bchr(97)%2bchr(115)%2bchr(115)%2bchr(95)%2bchr(95)] }}
为什么需要 %2b
在 URL 和 HTTP 请求中，加号 `+` 有特殊含义：
	- 在 URL 查询字符串中，`+` 表示空格
	- 在 HTML 表单数据中，`+` 也表示空格
    - %2b 在服务器端会被解码为 `+`这样就能确保加号作为字符串连接符使用，而不是被当作空格
如果我们直接使用 `+` 进行字符串拼接：
{{ ''[chr(95)+chr(95)+chr(99)+chr(108)+chr(97)+chr(115)+chr(115)+chr(95)+chr(95)] }}
服务器可能会将其解析为：
{{ ''[chr(95) chr(95) chr(99) chr(108) chr(97) chr(115) chr(115) chr(95) chr(95)] }}
%2b不行也可换其它连接符如jinja2中的~
{% set chr=url_for.__globals__['__builtins__'].chr %}
{{ ''[chr(95)~chr(95)~chr(99)~chr(108)~chr(97)~chr(115)~chr(115)~chr(95)~chr(95)] }}
```
