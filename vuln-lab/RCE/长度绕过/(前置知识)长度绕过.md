**>符号与>>符号**
```bash
>,重定向符号
echo "hello,world" > a.txt 将echo输出的内容写入a.txt，如果a.txt中有内容会被覆盖

>>,追加符号
echo "hello,world" >> a.txt 将echo输出的内容追加到a.txt，如果a.txt中有内容会被写在内容后不会覆盖

```

**命令换行符\\**
```bash
cat flag.php
可以写成
c\
a\
t\
 \ # \前是一个空格
flag.php
```

```
ls -t按照创建时间排序，最后创建的文件可以看作最年轻的文件，排列是年轻到老排序
ls -rt 与ls -t完全相反
```

**sh命令**
```
sh script.sh
# 使用sh解释器执行脚本
sh 文件名 作用是在当前shell环境中执行指定文件中的命令。
```
重要参数：
	-c：从字符串读取命令 `sh -c "ls"`
	-x：显示执行的命令（调试）
	-e：遇到错误立即退出
