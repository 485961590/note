## 一、学校与专业概况

### 1.1 学校概况

西南交通大学是**教育部直属全国重点大学**，国家首批"**双一流**""**211工程**"重点建设高校。学校坐落于四川省成都市，现有九里、犀浦、东部（国际）和峨眉四个校区。

### 1.2 学科地位

- 交通运输工程学科为**国家"A+"学科**（全国排名第一），入选国家"双一流"建设序列
- 交通运输专硕（086100）隶属**交通运输与物流学院**，是西南交大的王牌专业
- **专业学位**（非学术学位），全日制学习，学制3年

### 1.3 研究方向

086100 交通运输（专硕）在交通运输与物流学院下设两个方向：

| 方向 | 名称 | 复试笔试科目 | 说明 |
|------|------|-------------|------|
| 01 | 轨道交通运输 | 铁路运输组织 | 偏铁路、轨道交通 |
| **02** | **道路交通运输** | **交通工程学** | **偏交通规划、智能交通（即通常说的"交通工程"方向）** |

> 📌 本文档聚焦 **02 道路交通运输方向**（对应本科交通工程专业的考研方向）。

### 1.4 专硕 vs 学硕 对比速览

| 对比维度 | **专硕 086100（本文档）** | 学硕 0823Z2 交通工程 |
|----------|--------------------------|----------------------|

## 四、专业课（829管理运筹学）考试大纲与重点

> 📌 829管理运筹学是专硕和学硕的同一张试卷，考纲、题型、重点完全一致。

### 4.1 题型结构（2025年改革后）

| 题型 | 2025年最新分布 | 分值 |
|------|---------------|------|
| 单选题 | 15题 × 1分 | 15分 |
| 多选题 | 10题 × 1.5分 | 15分 |
| 简答题 | 10题 × 6分 | 60分 |
| 计算题 | 2题 × 15分 | 30分 |
| 建模题 | 3题 × 10分 | 30分 |
| **合计** | | **150分** |

> ⚠️ 2025年新增了客观题（单选+多选），简答题数量增加但单题分值降低，建模题拆分为3道小分值题目。计算+建模类题型占比约40%，是拿分关键。

### 4.2 核心教材章节重点（以寇玮华《运筹学》第2版为准）

#### 🔴 高频核心章节（每年必考，分值大）

| 章节 | 考频(近10年) | 分值 | 重点内容 | 常考题型 |
|------|-------------|------|----------|---------|
| **第2章 单纯形法** | 10/10 | 20-30分 | 标准形式转换、单纯形求解步骤、解的状态分析（唯一解/多重解/无界解/无可行解）、大M法、增加约束和变量的扩展 | 计算、简答 |
| **第9章 图与网络** | 10/10 | 20-30分 | 最短路径（Dijkstra）、最小生成树、**最大流算法**、**最小费用最大流**、网络优化 | 计算、简答、建模 |
| **第11章 排队论** | 10/10 | 15分 | M/M/1和M/M/C排队模型公式（**需背诵**，考试不提供公式）、系统组成和特征 | 计算、简答 |
| **第10章 统筹方法** | 9/10 | 15分 | 统筹图绘制规则、时间参数法确定关键路线、最少工时方案 | 计算、简答 |
| **第4章 灵敏度分析** | 8/10 | 5-10分 | 对bᵢ灵敏度分析（公式必背）、对cⱼ和aᵢⱼ的灵敏度分析、边际值与影子价格 | 计算、简答 |

#### 🟡 重要章节

| 章节 | 考频(近10年) | 分值 | 重点内容 | 常考题型 |
|------|-------------|------|----------|---------|
| **第3章 对偶问题** | 7/10 | 10-20分 | 对偶模型建立、弱/强对偶性、对偶单纯形法求解及扩展 | 计算、简答 |
| **第7章 整数规划** | 7/10 | 10-25分 | 分支定界法、0-1规划建模与求解 | 计算、简答、建模 |
| **第5章 运输问题** | 6/10 | 15-20分 | 初始可行解求法、位势法/闭合回路法、产销不平衡、转运问题、复杂运输问题建模 | 计算、简答 |
| **第6章 指派问题** | 5/10 | 10分 | 匈牙利法、非标准指派（最大化/人数不等） | 计算、简答 |

#### 🟢 一般章节

| 章节 | 考频(近10年) | 分值 | 重点内容 |
|------|-------------|------|----------|
| **第1章 线性规划基础** | 基础 | — | 建模步骤（简答常考）、模型特点及三种描述形式 |
| **第8章 动态规划** | 3/10 | 10分 | 基本概念（简答）、模型建立与求解（掌握课后习题） |
| **第12章 存储论** | 2/10 | 10分 | 基本概念（简答）、经济订货/生产批量模型公式（会证明）、报童问题 |

### 4.3 复习优先级总结

```
第一梯队（必考+高分值）：
  单纯形法 → 图与网络 → 排队论 → 统筹方法

第二梯队（高频+中等分值）：
  灵敏度分析 → 对偶问题 → 整数规划 → 运输问题 → 指派问题

第三梯队（偶尔考+巩固基础）：
  线性规划基础 → 动态规划 → 存储论
```

**建模题重点方向**：运输问题建模（含网络形式表达）、整数规划建模（互斥约束/依赖约束）、图与网络建模

历年真题覆盖年份：**1996-2000年、2002-2018年、2021年**的829管理运筹学真题。

可通过以下渠道获取：

## 六、复试内容与准备

> ⚠️ 重要提醒：复试笔试科目取决于你在研招网填报的研究方向。本文档针对**02 道路交通运输方向**（考交通工程学）。如果填报的是01轨道交通运输方向，则考铁路运输组织。

### 6.1 复试总览

| 项目 | 说明 |
|------|------|
| 复试形式 | 线下（笔试+面试） |
| 复试总分 | 300分（笔试100 + 外语50 + 面试150） |
| 成绩占比 | **初试60% + 复试40%** |
| 复试地点 | 西南交通大学犀浦校区 |
| 复试时间 | 预计2026年3月下旬 |

### 6.2 复试环节分解

#### 环节一：专业笔试（100分，120分钟）

- **科目**：交通工程学（道路交通运输方向）
- **参考书**：刘晓波、孙湛博《交通工程学原理与应用》，高等教育出版社，2019年
- **核心考查内容**：
  - **交通流理论**（三参数关系、交通流模型）— 核心重点
  - **交通规划四阶段法**（出行生成、出行分布、方式划分、交通分配）
  - **交通信号控制**（信号配时计算、交叉口设计）
  - **交通仿真基础**（VISSIM/TransCAD等软件原理）
- **笔试题型**：名词解释/简答题 + 计算与应用题（**需带计算器**）
- **重点提示**：教材课后习题是真题的重要来源

#### 环节二：外语测试（50分，≥5分钟）

- 听力（六级难度，交通领域英文素材）
- 口语（英文自我介绍 + 交通领域专业问答）
- 专业翻译（交通领域英文文献摘要双向翻译）
- **重点术语**：traffic flow, traffic assignment, signal timing, Level of Service (LOS), traffic capacity 等

#### 环节三：综合面试（150分，≥20分钟）

1. **3分钟自我介绍**（建议准备PPT）
2. **抽题专业问答**：理论题（如交通规划四阶段法）+ 工程情景题（如某交叉口优化方案设计）
3. **科研/项目/毕设追问**：按"问题→方案→结果→反思"四步法组织回答
4. **职业与科研规划**（含思政考核）

### 6.3 复试复习阶段规划

| 阶段 | 时间 | 任务 |
|------|------|------|
| 初试后-出分前 | 12月底-2月 | 通读《交通工程学原理与应用》教材，搭建知识框架 |
| 出分后-复试前 | 2月-3月 | 刷近5年复试真题，限时模拟笔试；准备英文自我介绍 |
| 复试前1-2周 | 3月中下旬 | 模拟面试练习，准备PPT；复习交通领域专业英语术语 |

### 6.4 关于同等学力加试

同等学力考生需加试两门本科主干课程，不计入复试总分但须及格（≥60分）。具体加试科目以学院当年通知为准。

## 八、备考经验与时间规划

### 8.1 三阶段备考总体规划

| 阶段 | 时间 | 数学（二） | 英语（二） | 政治 | 专业课（829） |
|------|------|-----------|-----------|------|-------------|
| **基础** | 3月-6月 | 高数+线代一轮 | 单词+阅读入门 | 暂不开始 | 通读教材 |
| **强化** | 7月-9月 | 高强度刷题 | 真题精刷 | 8月开始 | 逐章刷题 |
| **冲刺** | 10月-12月 | 真题+模拟卷 | 作文+真题 | 肖四肖八 | 真题反复刷 |

### 8.2 各科详细复习方法

#### 📐 数学（二）（150分）— 决定能否上岸

> 专硕考数二，**不考概率论**，范围小于数一，但高数和线代要学得更深。

| 内容 | 推荐方案 |
|------|----------|
| 高数基础 | 武忠祥基础课（多数经验推荐）或张宇30讲 |
| 线代 | 姜晓千（思路清晰）或李永乐 |
| 基础刷题 | 660题一阶 + 张宇1000题A组 |
| 强化刷题 | 李林880题（刷2-3遍）+ 姜晓千讲义 + 660二阶 |
| 冲刺模拟 | 张宇8+4、李林6+4、合工大超越、近15年真题限时 |

**数二特别提醒**：
- 高数部分不考：级数、曲线曲面积分、三重积分
- 线代部分与数一范围基本相同
- 计算能力是基本功，不要因"计算失误"丢分
- 每天建议投入**4-5小时**（比数一略少，因为范围更小）
- 目标：115-125分

#### 📊 829管理运筹学（150分）— 拉分关键

**复习节奏**：
- **暑假前**：通读寇玮华《运筹学》教材 + 做完配套习题集
- **7-9月**：逐章强化，重点章节课后题反复刷
- **10月起**：刷历年真题（1996年起都要做），训练答题规范
- **最后2个月**：背诵简答题考点 + 限时模拟

**复习要点**：
- 课本例题和习题集的每一道题都要吃透（可能出原题）
- 大题解题步骤繁杂，养成在旁边空白纸运算的习惯
- 建模题多练：运输问题建模、整数规划建模、图与网络建模
- 2025年新增客观题（单选+多选），注意练习选择题
- 扎实复习可达130+
- 2025年829平均分112分，建议目标120+

#### 📖 英语（二）（100分）— 难度低于英一

- **单词**：从备考第一天背到考前，推荐墨墨背单词/不背单词App，每天1-1.5小时
- **阅读**：跟唐迟《阅读的逻辑》，**只做真题，不做模拟题**（先做英一真题练手，再做英二真题）
- **作文**：10-11月开始跟石雷鹏，总结自己的模板
- **英二的特点**：新题型比英一简单、翻译为段落翻译（非长难句）、大作文以图表题为主
- **目标**：冲刺75-80+（英二拿分比英一容易）

#### 🏛️ 政治（100分）— 性价比最高

- **7-9月**：徐涛强化课 + 肖1000题（马原必须认真看）
- **10-11月**：腿姐技巧班 + 肖秀荣背诵手册 + 肖八选择题
- **12月**：狂背肖四大题 + 肖四/腿四选择题
- **考前突击**：选择题拉分关键，答题字迹工整很重要
- **目标**：65-70分

### 8.3 每日时间安排参考（暑假强化阶段为例）

| 时段 | 任务 | 说明 |
|------|------|------|
| 7:30 - 9:00 | 背单词 | 英语二词汇，每天200+ |
| 9:00 - 12:00 | 数学（二） | 看课+做题，高数和线代轮换 |
| 14:00 - 16:30 | 专业课（829） | 教材逐章学习+习题 |
| 16:30 - 17:30 | 线代专项 | 线代容易忘，每天保持手感 |
| 18:30 - 20:30 | 英语 | 阅读+精析（英一真题练手） |
| 20:30 - 22:00 | 数学收尾/复盘 | 错题整理+薄弱点回顾 |

> 9月之后调整为：数学4h / 政治2h / 英语2h / 单词1h / 专业课2h

### 8.4 专硕备考特别提示

1. **数二范围更小**：不考概率论是最大优势，可以把精力集中在高数和线代上
2. **英二难度更低**：作文和翻译都比英一简单，可以适当减少英语时间投入
3. **专业课是拉分关键**：829平均112分，冲130+能拉开巨大差距
4. **初试占比60%**：初试分高就有优势，但复试40%也不能掉以轻心
5. **复试竞争激烈**：2025年159人进复试录119人，淘汰率约25%

## 十、关键提醒与避坑指南

### 10.1 专硕报考优势

| 优势 | 说明 |
|------|------|
| 数学二不考概率论 | 复习范围更集中，比数一省力 |
| 英语二难度低 | 比英一更容易拿高分 |
| 招生人数多 | 统考90+人，容错率远高于学硕的5人 |
| 初试占比60% | 初试考得高，复试压力小 |
| 专业课与学硕相同 | 真题资料丰富，备考资源充足 |

### 10.2 专硕报考劣势

| 劣势 | 说明 |
|------|------|
| 分数线更高 | 340-355 vs 学硕的280左右 |
| 学费更贵 | 15000/年 vs 学硕8000/年 |
| 复试竞争大 | 159进119，淘汰约25% |
| 部分导师偏好学硕 | 联系导师时需确认是否招收专硕 |

### 10.3 备考避坑

| 坑 | 对策 |
|----|------|
| 以为数二简单就掉以轻心 | 高数部分考得比数一更深，不能轻敌 |
| 忽视专业课 | 829是拉分关键，平均112，冲130拉开差距 |
| 英语只做英二真题 | 英一真题也要做（题量大，练手效果好） |
| 死磕难题 | 效率＞时长，累了就休息 |
| 逃避弱项 | 弱项越拖越难补 |
| 复试才准备专业课 | 复试笔试交通工程学，初试后就要开始看 |
| 信息闭塞 | 加考研QQ群/关注小红书/B站经验帖 |

### 10.4 时间管理原则

1. **数学占比最大**（约35%时间），数二范围小但要学精
2. **专业课前期多投入**，冲130+拉开差距
3. **政治后期突击**，性价比最高
4. **英语细水长流**，单词从第一天背到最后
5. **每周至少休息半天**，保持身体和精神状态
