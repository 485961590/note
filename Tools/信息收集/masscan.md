# masscan 端口扫描实用指南

`masscan` 是一个高速 TCP 端口扫描器，适合在信息收集阶段快速确认大范围 IP 的开放端口。它主要负责“端口发现”，不负责完整的服务版本识别、操作系统识别或漏洞验证。

以下命令只适用于自己控制的主机、靶场或明确授权的测试目标。masscan 发包速度很高，扫描前应确认目标范围、端口范围和允许的请求速率。

## 1. 安装与检查

Kali / Debian：

```bash
sudo apt update
sudo apt install masscan
```

源码编译：

```bash
git clone https://github.com/robertdavidgraham/masscan.git
cd masscan
make
sudo make install
```

检查是否安装成功：

```bash
masscan --version
masscan --help
```

Linux 下通常需要 root 权限发送原始数据包；Windows 下通常需要管理员权限，并可能需要额外的抓包/网卡驱动支持。

## 2. 基本语法

```bash
masscan <目标> -p<端口> [选项]
```

目标可以是单个 IP、IP 范围或 CIDR 网段：

```bash
# 单个主机
masscan 192.168.1.10 -p80,443

# IP 范围
masscan 192.168.1.1-254 -p22,80,443

# CIDR 网段
masscan 192.168.1.0/24 -p1-1024
```

`-p` 后可以写单个端口、逗号分隔的端口，或端口范围：

```bash
masscan 192.168.1.10 -p22
masscan 192.168.1.10 -p22,80,443,8080
masscan 192.168.1.10 -p1-65535
masscan 192.168.1.10 -p80,8000-8100
```

## 3. 常用参数速查

### 目标与端口

| 参数 | 作用 |
|------|------|
| `<IP>` | 扫描单个 IP |
| `<IP1>-<IP2>` | 扫描连续 IP 范围 |
| `<CIDR>` | 按网段扫描，例如 `10.0.0.0/8` |
| `-p PORTS` | 指定 TCP 端口或端口范围 |
| `--exclude IP/RANGE` | 排除指定 IP 或网段，可重复使用 |
| `--excludefile FILE` | 从文件读取要排除的 IP 或网段 |

### 速度与请求

| 参数 | 作用 |
|------|------|
| `--rate N` | 设置每秒发送的数据包数量 |
| `--wait N` | 扫描结束后等待 N 秒再退出，便于接收迟到的响应 |
| `--banners` | 尝试获取部分服务的 Banner，产生的请求更多 |
| `--source-port PORT` | 指定源端口，排查特定网络设备或防火墙策略时使用 |

### 网卡与路由

| 参数 | 作用 |
|------|------|
| `--adapter-ip IP` | 指定发送数据包使用的本机 IP |
| `--adapter-mac MAC` | 指定本机网卡 MAC 地址 |
| `--router-mac MAC` | 指定下一跳网关 MAC 地址 |
| `--iflist` | 列出 masscan 识别到的网卡信息 |

### 输出与配置

| 参数 | 作用 |
|------|------|
| `-oL FILE` | 保存为列表格式 |
| `-oJ FILE` | 保存为 JSON 格式 |
| `-oX FILE` | 保存为 XML 格式 |
| `-oG FILE` | 保存为 Grepable 格式 |
| `--echo` | 输出当前配置，便于保存为配置文件 |
| `-c FILE` | 从配置文件加载扫描参数 |

不同版本的参数可能略有差异，以 `masscan --help` 输出为准。

## 4. 最常用的扫描方式

### 快速确认 Web 端口

```bash
masscan 192.168.1.0/24 -p80,443,8080,8443 --rate 1000
```

### 扫描常见管理端口

```bash
masscan 192.168.1.0/24 -p22,23,3389,5900,5985,5986 --rate 500
```

不建议一开始就扫描全端口。先扫描少量常用端口确认网络路径和结果，再扩大范围。

### 扫描主机全部 TCP 端口

```bash
masscan 192.168.1.10 -p1-65535 --rate 1000
```

对单个主机可以适当提高速率；对网段扫描时，应根据网络带宽、设备承受能力和授权要求重新设置 `--rate`。

### 尝试获取服务 Banner

```bash
masscan 192.168.1.10 -p22,80,443 --banners --rate 500
```

Banner 结果只能作为初步线索，版本信息可能不完整或不准确。发现开放端口后，建议使用 Nmap 对重点主机做服务版本识别：

```bash
nmap -sV -p22,80,443 192.168.1.10
```

## 5. 限速、排除与保存结果

### 限制扫描速率

```bash
masscan 192.168.1.0/24 -p1-1024 --rate 500
```

速率不是越高越好。速率过高会造成丢包、结果不完整，也可能触发防火墙、IDS 或交换机的防护策略。建议按以下思路调整：

- 小范围靶场：从 `--rate 500` 或 `--rate 1000` 开始；
- 正式授权测试：根据甲方约定和网络承受能力设置；
- 出现大量超时或结果明显不稳定：降低 `--rate`，并适当增加 `--wait`。

### 排除不应扫描的地址

直接排除单个 IP：

```bash
masscan 192.168.1.0/24 -p1-1024 \
  --exclude 192.168.1.1 \
  --rate 500
```

从文件读取排除范围，文件内容一行一个 IP 或 CIDR：

```text
192.168.1.1
192.168.1.250-192.168.1.254
10.10.0.0/16
```

执行扫描：

```bash
masscan 192.168.1.0/24 -p1-65535 \
  --excludefile exclude.txt \
  --rate 1000
```

### 保存结果

列表格式便于人工查看：

```bash
masscan 192.168.1.0/24 -p1-1024 \
  --rate 1000 \
  -oL masscan.lst
```

JSON 格式便于后续脚本处理：

```bash
masscan 192.168.1.0/24 -p1-65535 \
  --rate 1000 \
  -oJ masscan.json
```

XML 格式便于交给部分安全工具继续处理：

```bash
masscan 192.168.1.0/24 -p80,443 \
  --rate 1000 \
  -oX masscan.xml
```

## 6. 配置文件复用

参数较多或需要重复执行时，可以先导出配置：

```bash
masscan 192.168.1.0/24 -p80,443 --rate 1000 --echo > scan.conf
```

检查并按需修改 `scan.conf` 后执行：

```bash
masscan -c scan.conf
```

配置文件和 JSON 结果中可能包含内部 IP、扫描范围等敏感信息，不要直接上传到公开仓库。

## 7. 推荐工作流

### 第一步：确认少量常用端口

```bash
masscan 192.168.1.0/24 \
  -p21,22,23,25,53,80,110,139,143,443,445,993,995,1433,3306,3389,5432,6379,8080,8443 \
  --rate 500 \
  -oJ quick.json
```

### 第二步：扩大重点主机的端口范围

```bash
masscan 192.168.1.10 -p1-65535 --rate 1000 -oJ host-192.168.1.10.json
```

### 第三步：用 Nmap 做精确确认

根据 masscan 结果整理开放端口，再进行服务识别：

```bash
nmap -sV -sC -p22,80,443 192.168.1.10
```

masscan 适合快速“找门”，Nmap 适合确认“门后是什么”。两者不要混为同一种扫描器。

## 8. 常见问题

### 扫描没有结果

依次检查：

- 目标 IP 或 CIDR 是否写正确；
- `-p` 是否指定了正确的端口；
- 本机是否能到达目标网段；
- 是否需要 root 或管理员权限；
- 本机防火墙、出口防火墙或目标防火墙是否丢弃了探测包；
- `--rate` 是否过高导致响应大量丢失。

先对一个已知开放端口的主机做小范围测试，排除网络路径问题：

```bash
masscan 192.168.1.10 -p80 --rate 100
```

### 结果和 Nmap 不一致

这是常见情况，原因可能包括：

- 两次扫描的时间不同，服务状态发生变化；
- masscan 速率过高，响应包被丢弃；
- 防火墙对不同探测方式做了差异化处理；
- 目标端口处于过滤状态，而不是稳定开放状态；
- masscan 只发现了 SYN 响应，尚未完成完整的服务确认。

降低速率后重新扫描，再用 Nmap 或其他 TCP 连接工具复核。

### `failed to detect route` 或网卡相关错误

先查看网卡：

```bash
masscan --iflist
```

多网卡、虚拟机或复杂路由环境中，可以显式指定本机 IP，必要时指定网关 MAC：

```bash
masscan 192.168.1.10 -p80 \
  --adapter-ip 192.168.1.100 \
  --router-mac AA:BB:CC:DD:EE:FF \
  --rate 100
```

只有在确实存在路由或网卡识别问题时才需要手动指定这些参数。

### 扫描速度很快但结果不稳定

先降低 `--rate`，再增加等待时间：

```bash
masscan 192.168.1.0/24 -p80,443 --rate 200 --wait 5
```

对重点主机重复扫描并比较结果，比单纯提高速率更可靠。

## 9. 记忆版

```bash
# 常用端口
masscan TARGET -p22,80,443 --rate 500

# 全端口
masscan TARGET -p1-65535 --rate 1000

# 保存 JSON
masscan TARGET -p1-65535 --rate 1000 -oJ result.json

# 排除地址
masscan TARGET -p1-1024 --exclude 192.168.1.1 --rate 500

# 获取 Banner
masscan TARGET -p22,80,443 --banners --rate 500
```
