# 搜索引擎语法 (Google Hacking / Dorking)

> 利用搜索引擎索引发现目标暴露的页面、文件和信息
> 适用引擎: Google, Bing, DuckDuckGo, 百度
> 零风险 — 不向目标发任何请求

---

## 基础语法

| 语法 | 作用 | 示例 |
|------|------|------|
| `site:domain` | 限制搜索范围为指定域名 | `site:xxx.edu.cn` |
| `inurl:keyword` | URL 中包含关键词 | `inurl:admin` |
| `intitle:keyword` | 页面标题包含关键词 | `intitle:"后台"` |
| `intext:keyword` | 页面正文包含关键词 | `intext:"password"` |
| `filetype:ext` | 限定文件类型 | `filetype:pdf` |
| `-keyword` | 排除关键词 | `-inurl:www` |
| `"keyword"` | 精确匹配 | `"index of"` |
| `*` | 通配符 | `"*@xxx.edu.cn"` |

## 组合搜索模式

### 信息收集

```
site:xxx.edu.cn

site:xxx.edu.cn inurl:login                           # 登录入口

site:xxx.edu.cn inurl:portal                          # 门户
site:xxx.edu.cn inurl:api                             # API 接口
site:xxx.edu.cn inurl:swagger                         # Swagger 文档
site:xxx.edu.cn intitle:"登录"                         # 中文登录页
site:xxx.edu.cn intitle:"管理"                         # 管理页面
site:xxx.edu.cn intitle:"index of"                    # 目录浏览

```

## 搜索引擎差异

| 引擎 | 优点 | 缺点 |
|------|------|------|
| **Google** | 收录最全，语法支持最完整 | 国内需科学上网，中文内容不如 Bing |
| **Bing** | 国内直接可用，中文收录好 | 部分高级语法不支持 |
| **百度** | 国内内容最全 | 语法支持差，`filetype` 等不支持 |
| **DuckDuckGo** | 隐私友好 | 收录量少 |

**国内高校推荐**：Bing 为主，Google 为辅。

---

## 实操策略

1. **先用宽泛语法**（`site:xxx.edu.cn`）了解搜索引擎收录了多少页面
2. **按类型逐批搜索**：登录入口 -> 动态页面 -> 文件泄露 -> 错误信息
3. **每批只看前 2-3 页**，不需要翻到底
4. **重点记录**：新出现的域名、带参数的 URL、暴露的文档/配置文件
5. **Bing 和 Google 分别搜一遍**，结果可能不同
