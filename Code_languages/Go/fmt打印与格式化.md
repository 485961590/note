# Go fmt 打印与格式化

> Go 标准库 `fmt` 包的核心用法：三种打印接口 + 一套格式动词。打印调试、日志输出、构造字符串全靠它。格式化符号和其他语言（C 的 printf）相似，但 `%v` / `%+v` / `%#v` 三件套是 Go 独有的排错利器。

---

## 一、打印函数分类

### 1. 标准输出（fmt 包）

| 函数 | 特点 | 换行 | 自动空格 |
|------|------|------|----------|
| `fmt.Print()` | 直接输出 | 否 | 否 |
| `fmt.Println()` | 输出后换行 | 是 | 是（参数间） |
| `fmt.Printf()` | 格式化输出 | 否（需手动加 `\n`） | 否 |

> 记忆：**ln = 换行**，**f = format 格式串**。

```go
fmt.Print("a", 1)        // a1，不换行
fmt.Println("a", 1)      // a 1（换行），参数间自动加空格
fmt.Printf("%d\n", 42)   // 42（换行），\n 要自己写
```

### 2. 字符串格式化（返回字符串）

| 函数 | 用途 |
|------|------|
| `fmt.Sprintf()` | 返回格式化后的字符串，不打印 |
| `fmt.Errorf()` | 返回格式化后的错误对象 |

```go
s := fmt.Sprintf("%s-%d", "user", 42)   // "user-42"
e := fmt.Errorf("code=%d", 500)          // error 对象
```

`fmt.Errorf` 带 `%w` 可包装错误，保留错误链（Go 1.13+），配合 `errors.Is` / `errors.As` 使用：

```go
return fmt.Errorf("读取配置失败: %w", err)
```

### 3. 错误 / 日志输出

| 函数 | 特点 |
|------|------|
| `fmt.Fprint(os.Stderr, ...)` | 输出到指定流（如标准错误） |
| `log.Print()` / `log.Printf()` / `log.Println()` | 带时间戳的日志输出，程序继续运行 |
| `log.Fatal()` / `log.Fatalf()` / `log.Fatalln()` | 打印日志后调用 `os.Exit(1)` 退出程序 |
| `log.Panic()` / `log.Panicf()` / `log.Panicln()` | 打印日志后触发 panic |

`Fprint` 系列第一个参数是任意 `io.Writer`（文件、网络连接、缓冲器都行），不止标准错误：

```go
fmt.Fprintf(file, "time=%s status=%d\n", time.Now(), 200)   // 写文件
fmt.Fprintf(os.Stderr, "出错了: %v\n", err)                  // 标准错误输出
log.Printf("status=%d", 500)    // 2026/08/10 15:08:00 status=500，自带时间戳

log.Fatalf("连接失败: %v", err)  // 打印后 os.Exit(1)，程序立即退出，常用于 init/启动检查
log.Panicf("未处理异常: %v", err) // 打印后触发 panic，可用 recover 捕获
```

> 三个家族都有 `Print` / `Printf` / `Println` 变体，`f` 表示按格式串输出，`ln` 表示末尾换行。区别只在收尾动作：`Print` 继续运行、`Fatal` 退出程序、`Panic` 触发 panic。

## 通用动词（最常用）

排错时 90% 只用这三个：

| 动词 | 含义 | 示例（`p := Point{1, 2}`，`n := 42`） |
|------|------|------|
| `%v` | 默认格式 | `%v` → `{1 2}`，`42` |
| `%+v` | 带字段名的结构体 | `%+v` → `{X:1 Y:2}` |
| `%#v` | Go 语法表示（带类型和字段名） | `%#v` → `main.Point{X:1, Y:2}` |
| `%T` | 值的类型 | `%T` → `main.Point` |

```go
type Point struct{ X, Y int }
p := Point{1, 2}

fmt.Printf("%v\n", p)    // {1 2}          排错先用它
fmt.Printf("%+v\n", p)   // {X:1 Y:2}      想看字段名用这个
fmt.Printf("%#v\n", p)   // main.Point{X:1, Y:2}  最详细，含类型
fmt.Printf("%T\n", p)    // main.Point
```

**何时用哪个：**
- `%v` — 日常打印、写日志，最通用
- `%+v` — 调试结构体，想知道字段名时
- `%#v` — 想知道完整类型时（含包名）

## 数值动词

### 布尔

| 动词 | 含义 | 示例 |
|------|------|------|
| `%t` | true / false | `%t` → `true` |

### 整数

| 动词 | 含义 | 示例（`n := 255`） |
|------|------|------|
| `%d` | 十进制（最常用） | `255` |
| `%b` | 二进制 | `11111111` |
| `%o` | 八进制 | `377` |
| `%O` | 八进制带前缀 | `0o377` |
| `%x` | 十六进制小写 | `ff` |
| `%X` | 十六进制大写 | `FF` |
| `%c` | 按 Unicode 码点输出字符 | `%c`(65) → `A` |
| `%q` | 单引号字符字面量 | `%q`(65) → `'A'` |
| `%U` | Unicode 格式 | `U+0041` |
| `%#U` | Unicode 带字符 | `U+0041 'A'` |

### 浮点数

| 动词 | 含义 | 示例（`f := 3.14159`） |
|------|------|------|
| `%f` | 固定小数（默认 6 位） | `3.141590` |
| `%.2f` | 保留 2 位小数 | `3.14` |
| `%e` | 科学计数法 | `3.141590e+00` |
| `%g` | 自动选 %e 或 %f（精简） | `3.14159` |
| `%G` | 同上但用大写 E | `3.14159E+00` |

> `%g` 是浮点数的"默认格式"：小数位数少用 `%f`，多了自动切科学计数法，日常打印浮点用它最省心。

## 字符串与字节

| 动词 | 含义 | 示例（`s := "hi"`） |
|------|------|------|
| `%s` | 原样输出 | `hi` |
| `%q` | 带双引号，转义特殊字符 | `"hi"` |
| `%x` | 十六进制，每字节 2 位 | `6869` |
| `%X` | 十六进制大写 | `6869` |

`% x`（加空格标志）输出带空格的十六进制，常用于看二进制内容：

```go
fmt.Printf("% x\n", []byte{0xDE, 0xAD})   // de ad
```

## 指针

| 动词 | 含义 | 示例 |
|------|------|------|
| `%p` | 内存地址（16 进制带 0x） | `0xc0000140a0` |

```go
x := 1
fmt.Printf("%p\n", &x)   // 0xc0000140a0（每次运行地址可能不同）
```

## 宽度、精度与标志

格式：`%[标志][宽度][.精度]动词`

### 宽度与精度

```go
fmt.Printf("%5d\n", 42)     // "   42"  宽度 5，右对齐，空格补齐
fmt.Printf("%-5d\n", 42)    // "42   "  左对齐
fmt.Printf("%05d\n", 42)    // "00042"  前导 0 补齐
fmt.Printf("%6.2f\n", 3.14159)  // "  3.14"  总宽 6，保留 2 位小数
fmt.Printf("%.3s\n", "hello")   // "hel"  截断前 3 个字符
```

> 宽度填在左边（`%-5d` 是负号+宽度表示左对齐），精度用小数点开头（`.2f`）。

### 常用标志

| 标志 | 含义 | 示例 |
|------|------|------|
| `+` | 数值强制显示正负号 | `%+d`(42) → `+42` |
| `-` | 左对齐 | `%-5d` → `42   ` |
| `#` | 交替格式（加前缀/进制标记） | `%#x`(255) → `0xff`，`%#b` → `0b11111111` |
| `0` | 前导 0 补齐 | `%05d` → `00042` |
| 空格 | 数字符号位留空 / 字符串按字节分格 | `% d`(42) → ` 42` |

## 一张表速查

```go
fmt.Printf("%v\n", 123)        // 123
fmt.Printf("%+v\n", point)     // {X:1 Y:2}
fmt.Printf("%#v\n", point)     // main.Point{X:1, Y:2}
fmt.Printf("%T\n", point)      // main.Point
fmt.Printf("%t\n", true)       // true
fmt.Printf("%d\n", 255)        // 255
fmt.Printf("%b\n", 255)        // 11111111
fmt.Printf("%x\n", 255)        // ff
fmt.Printf("%c\n", 65)         // A
fmt.Printf("%.2f\n", 3.14159)  // 3.14
fmt.Printf("%g\n", 3.14159)    // 3.14159
fmt.Printf("%s\n", "hi")       // hi
fmt.Printf("%q\n", "hi")       // "hi"
fmt.Printf("%p\n", &x)         // 0xc0000140a0
fmt.Printf("%5d\n", 42)        //    42
```

## 记忆要点

- **ln 换行、f 格式串**：`Print` / `Println` / `Printf` 三件套，Sprint 和 Fprint 同理
- **排错三件套**：`%v` 默认 → `%+v` 带字段名 → `%#v` 带类型，层层加码
- **数字进制**：`%d` 十进制、`%b` 二进制、`%o` 八进制、`%x` 十六进制
- **浮点**：日常用 `%g`，要固定位数用 `%.2f`
- **`%q`** 永远输出"带引号的可安全转义"版本，防止特殊字符捣乱
- **`%p`** 打印内存地址，判断切片底层数组是否相同很有用
- **`%w`** 只在 `fmt.Errorf` 里用，用于错误链包装
- 自定义类型实现 `String() string` 方法后，`%v` / `%s` 会调用它
